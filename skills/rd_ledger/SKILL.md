# 技能：rd_ledger

把「已归集的费用」变成**能交给税务的交付物**。

## 输入要求

依赖本次会话的业务黑板状态：
- `expenses`（已归集费用）—— **必须有**，否则明确告知"还没有归集任何费用"
- `allocations`（人员人工分摊）—— 有则输出分摊表
- `projects` / `timesheets` —— 用于判断备查资料是否已具备

## 输出

1. **研发支出辅助账**（按 8 类口径，含笔数与金额）
2. **限额校验**：其他相关费用 ≤ 可加计扣除总额的 10%（加计扣除口径；高企是 20%，两者不同）
3. **人员人工分摊表**（按工时占比）
4. **留存备查资料清单**（7 项，逐条标注 已具备 / 待补充）

## 政策依据

- 财税〔2015〕119 号：享受加计扣除必须建立研发支出辅助账
- 国家税务总局公告 2015 年第 97 号 / 2023 年第 7 号：辅助账样式与留存备查资料清单

**不要编造金额**；没有归集记录就如实说没有。
